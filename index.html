FAQ

Questions fréquentes

Faut-il des compétences techniques ?
Non. Si vous savez copier-coller un message WhatsApp, vous savez utiliser Stafflo. C'est un fichier HTML que vous ouvrez dans votre navigateur. Aucune installation, aucun compte requis pour commencer.
Où sont stockées mes données ?
Dans Supabase — une base de données cloud sécurisée que vous contrôlez. Vos données ne transitent jamais par nos serveurs. Vous pouvez aussi exporter votre CRM en JSON à tout moment.
Ça marche sur téléphone ?
Oui. Stafflo est conçu mobile-first. Il fonctionne parfaitement sur iPhone, Android, iPad et ordinateur. La même interface, synchronisée partout via Supabase.
Ça marche pour Airbnb et Booking ?
Oui. L'extraction automatique reconnaît les formats Airbnb (email et message in-app) et Booking.com. Elle reconnaît aussi les conversations WhatsApp directes.
Je peux gérer plusieurs villas ?
La version actuelle gère une villa par compte. La gestion multi-villas est en développement et sera disponible pour les founding members en priorité.
C'est différent de Lodgify ou Guesty ?
Complètement. Lodgify et Guesty synchronisent les calendriers pour les gestionnaires de 10+ appartements. Stafflo gère la relation client premium — le WhatsApp, les repas, la logistique, le staff. Ce que les grands outils ne font pas.
